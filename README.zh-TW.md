# Unlinked Mentions Picker

[English](README.md) | **繁體中文** | [日本語](README.ja.md)

Obsidian 外掛：找出「提到筆記名稱或別名、但尚未連結」的地方，一鍵建立連結。支援兩個方向：

- **本筆記內**：目前筆記裡提到*其他*筆記的地方。
- **提及本筆記**：*其他*筆記裡提到目前筆記的地方。

預設全選，取消不要的項目後一次建立所有連結。

## 功能

- 在右側欄新增一個分頁（圖示：打勾清單），頂端可切換兩種模式。
- 每個項目顯示行號與前後文，點前後文可跳到編輯器中的位置。
- **本筆記內**
  - 每個項目顯示連結目標。同名對應多篇筆記時，要先從下拉選單選擇目標。
  - 提及互相重疊時（例如「東京」與「東京塔」），預設勾選較長的那個；勾選其中一個會自動取消另一個。
- **提及本筆記**
  - 依所在筆記分組，一鍵在所有筆記中建立連結。
  - 屬於較長筆記名稱一部分的提及（例如有「東京塔」這篇筆記時，「東京塔」裡的「東京」）會列出，但預設不勾。
- 略過 frontmatter、既有連結／嵌入與程式碼區塊；表格中的 `|` 會自動跳脫。
- 連結格式依照你的設定（wikilink 或 Markdown）。
- 復原：開在編輯器中的筆記，每篇按一次 `Ctrl+Z` 即可復原；沒有開啟的筆記會直接寫入檔案。
- **支援中日韓文字**：英數字需要斷詞邊界（`NS` 不會比對到 `NSFW`），中日韓文字則任何位置都能比對，所以句子中間的提及也找得到——Obsidian 內建的未連結提及做不到這點。
- 只使用 Obsidian 公開 API。

## 使用方式

1. 點右側欄頂端的打勾清單圖示，或從指令面板執行指令（見下方）。
2. 在側欄頂端選擇「本筆記內」或「提及本筆記」。
3. 打開一篇筆記，清單會自動更新，預設全部勾選。
4. 逐項檢查：點前後文可到編輯器中確認，取消不想連結的項目。
5. 按「建立連結（n）」。

按鈕：全選／全不選／建立連結。

## 指令

- 開啟未連結提及清單
- 列出其他筆記中提到本筆記的未連結提及

## 介面語系

介面語言跟隨 Obsidian 的顯示語言，支援英文、繁體中文、日文；其他語系顯示英文。

## 安裝

### 手動安裝

1. 從最新的 [release](../../releases) 下載 `main.js`、`manifest.json`、`styles.css`。
2. 放到 `<你的 vault>/.obsidian/plugins/unlinked-mentions-picker/`。
3. 重新載入 Obsidian，在「設定 → 社群外掛」啟用 **Unlinked Mentions Picker**。
