# Unlinked Mentions Picker

[English](README.md) | [繁體中文](README.zh-TW.md) | **日本語**

ノート名（またはエイリアス）がリンクされずに書かれている箇所を見つけ、ワンクリックでリンクにする Obsidian プラグインです。次の 2 方向に対応しています。

- **このノート内**：現在のノートの中で、*他の*ノートに言及している箇所。
- **このノートへの言及**：*他の*ノートの中で、現在のノートに言及している箇所。

すべて選択済みの状態で表示されるので、不要なものだけチェックを外して、まとめてリンクを作成できます。

## 機能

- 右サイドバーにタブを追加します（アイコン：チェック付きリスト）。上部で 2 つのモードを切り替えます。
- 各項目には行番号と前後の文が表示されます。前後の文をクリックするとエディタの該当箇所へ移動します。
- **このノート内**
  - 各項目にリンク先のノートが表示されます。同じ名前のノートが複数ある場合は、先にドロップダウンでリンク先を選択します。
  - 言及が重なっている場合（例：「東京」と「東京タワー」）は長い方が既定で選択され、一方を選ぶともう一方は解除されます。
- **このノートへの言及**
  - 言及があるノートごとにまとめて表示され、それらすべてのノートにワンクリックでリンクを作成します。
  - より長いノート名の一部になっている言及（例：「東京タワー」というノートがあるときの「東京タワー」内の「東京」）は表示されますが、既定では選択されません。
- frontmatter、既存のリンク／埋め込み、コードブロックはスキップします。表内の `|` は自動でエスケープします。
- リンクの形式は設定（wikilink または Markdown）に従います。
- 元に戻す：エディタで開いているノートは、ノートごとに `Ctrl+Z` 1 回で元に戻せます。開いていないノートはファイルに直接書き込まれます。
- **CJK 対応**：英数字には単語境界が必要ですが（`NS` は `NSFW` にマッチしません）、中国語・日本語・韓国語の名前はどこでもマッチするため、文中の言及も見つかります。Obsidian 標準の「未リンクの言及」では見つからない箇所です。
- Obsidian の公開 API のみを使用しています。

## 使い方

1. 右サイドバー上部のチェック付きリストのアイコンをクリックするか、コマンドパレットからコマンドを実行します（下記参照）。
2. サイドバー上部で「このノート内」か「このノートへの言及」を選びます。
3. ノートを開くとリストが自動で更新され、すべて選択された状態で表示されます。
4. リストを確認します。前後の文をクリックしてエディタで確かめ、リンクしたくない項目のチェックを外します。
5. 「リンクを作成（n）」をクリックします。

ボタン：すべて選択／選択解除／リンクを作成。

## コマンド

- 未リンクの言及リストを開く
- 他のノートにあるこのノートへの未リンクの言及を表示

## 表示言語

インターフェースは Obsidian の表示言語に従います（英語・繁体字中国語・日本語）。それ以外の言語では英語で表示されます。

## インストール

### 手動インストール

1. 最新の [release](../../releases) から `main.js`、`manifest.json`、`styles.css` をダウンロードします。
2. `<vault>/.obsidian/plugins/unlinked-mentions-picker/` に置きます。
3. Obsidian を再読み込みし、「設定 → コミュニティプラグイン」で **Unlinked Mentions Picker** を有効にします。
